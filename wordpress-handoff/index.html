Стек & план

Минимален набор плъгини. Темата държи дизайна, плъгините — функционалността. Без page builder. Direct theme + ACF + Gutenberg блокове само където има смисъл.

Задължителни плъгини

  • Advanced Custom Fields (ACF) — за event meta полета. Free версия е достатъчна.
  • Yoast SEO — meta, OG, sitemap.
  • WP Rocket (платен) — cache. SuperHosting е бавен без cache. Алтернатива: W3 Total Cache (free).
  • Wordfence Security — задължително за production. Brute-force защита, malware scan.
  • UpdraftPlus — автоматичен backup в Google Drive / Dropbox.
  • Complianz — GDPR cookie banner (Европейски трафик).

Какво НЕ ползваме

  • ❌ Elementor / Divi / WPBakery — твърде тежки, чупят дизайн системата.
  • ❌ Готови теми (Astra/OceanWP) — ние сме custom тема.
  • ❌ Контактна форма като Contact Form 7 за резервации — резервациите минават през app.meet-bg.com, не през marketing сайта.

Папкова структура

Темата живее в wp-content/themes/meetbg-theme/:

style.css

WordPress изисква този файл — той държи theme metadata. Истинският CSS е в assets/css/tokens.css и assets/css/theme.css, които се enqueue-ват от functions.php.

theme.json

WordPress 6+ ползва theme.json за да даде на Gutenberg редактора достъп до брандовите цветове и шрифтове. Това е буквалното отражение на дизайн системата — палитра, типография, spacing scale.

"
Slug-овете в color.palette се превръщат в CSS променливи като var(--wp--preset--color--gold) — ползвай ги в Gutenberg блокове.

functions.php

Theme bootstrap: enqueue на CSS/JS, theme support, menu locations, и зареждане на Event CPT файла.

CPT: Event (Вечеря)

Всяка вечеря е WordPress post от тип event. Дава ни админски UI, permalinks, REST API, и feed-ове безплатно. Две taxonomy-та за филтриране: event_city и event_country.

ACF полета

Импортирай този JSON в ACF → Tools → Import. Той създава field group "Детайли за вечеря" който се появява на всеки Event post.

front-page.php

Главната страница, която WordPress показва при posewing на site root. Просто оркестрира template parts.

single-event.php

Страницата на една вечеря — пълен detail view с booking sidebar. Линковете "Резервирай" сочат към app.meet-bg.com (Stripe payment).

main.js

Минимум JS — smooth scroll за anchor links. Темата е почти изцяло server-rendered; интерактивността е в app.meet-bg.com.

SuperHosting deployment

Стъпка по стъпка качване от локалната машина до live на meet-bg.com.

01

Локална подготовка

В директорията на темата:

02

SuperHosting cPanel

  1. Влез в cPanel: https://cp.superhosting.bg
  2. File Manager → public_html/wp-content/themes/
  3. Upload → избери meetbg-theme.zip
  4. Right-click на zip-а → Extract
  5. Изтрий zip-а след extract
03

WordPress активация

  1. Влез в /wp-admin
  2. Appearance → Themes → активирай "Meet-BG"
  3. Settings → Permalinks → Post name → Save (flush на rewrite rules)
04

Плъгини

Инсталирай по реда:

  1. Advanced Custom Fields → импортирай inc/acf-fields.json
  2. Yoast SEO → конфигурирай OG image, sitemap
  3. WP Rocket → page cache, minify, lazy load
  4. Wordfence Security → enable firewall
  5. UpdraftPlus → schedule weekly backup в Google Drive
  6. Complianz → конфигурирай GDPR banner
05

Менюта

Appearance → Menus → създай 4 менюта:

  • Main nav (4 items: Вечери, Как работи, За нас, Контакт) → location: primary
  • Footer · Платформа → location: footer-platform
  • Footer · Страни → location: footer-countries
  • Footer · Компания → location: footer-company
06

SSL & домейн

  1. cPanel → SSL/TLS Status → Run AutoSSL (Let's Encrypt free)
  2. Ако домейнът е регистриран другаде → насочи nameservers към SuperHosting

Pre-launch checklist

Преди да пуснем live, минаваме през всичко:

  • Homepage зарежда под 2 секунди (тест на gtmetrix.com)
  • Mobile breakpoints (320px, 768px, 1024px) — всички секции четими
  • Event single page работи с тестова вечеря
  • Всички 4 менюта показват правилни линкове
  • OG image за social sharing (Facebook, LinkedIn debugger)
  • GDPR cookie banner показва се за EU посетители
  • Контактна форма (ако има) тества се с реален email
  • HTTPS активен, без mixed content warnings
  • Sitemap.xml достъпен на /sitemap_index.xml
  • robots.txt разрешава индексиране
  • Google Analytics 4 / Plausible инсталиран
  • Facebook Pixel инсталиран (ако правиш ads)
  • Backup тестван — restore работи
  • Wordfence scan чист
  • 404 страница изглежда брандово (не дефолтната)
  • meta-bg.uk / .de / .us redirects конфигурирани (ако са клонинги)

Следваща стъпка

След като marketing сайтът е live, същия дизайн system се прехвърля в app.meet-bg.com — там вече е React/Next.js (v2 plan). Marketing темата и app-ът споделят tokens.css, така че брандингът остава consistent.
